# StockScreening

東証上場銘柄と NYダウ・NASDAQ-100 構成銘柄を絞り込む GitHub Pages アプリです。
GitHub Actions が価格・配当データを生成し、main の更新時と定期実行時に公開します。

## 条件式によるスクリーニング

条件入力は一つの条件式に統一しています。９つのプリセットを選ぶか、式を直接編集して実行します。
「自然言語で条件を指定」も必ず同じ式を生成し、編集欄に表示して実行します。
API が古い条件リストを返した場合や、表現できない条件がある場合は結果を更新せず理由を表示します。

```
dividend_yield >= 3 && rights_days >= 0 && rights_days <= 30
(close > sma(20) && rsi(14) < 50) || weekly_up(4)
rights_date >= "2026-11-01" && rights_date <= "2026-11-30"
```

利用できる指標と文法は画面の「使える指標と書き方」に表示します。
AND/OR、比較、四則演算、移動平均、RSI、期間騰落率、出来高、配当などを組み合わせられます。
専用パーサーで解釈し、JavaScript の eval は使用しません。
未取得の値が必要な比較は不成立です。high/low は調整済終値の最高/最低、RSI は単純平均方式です。
期間関数の日数は営業日、rights_days は日本時間の今日からの暦日です。
weekly_up(4) は基準日から７日ずつ遡る４区間の終値が各区間で上昇していることを表します。

プリセットは半導体関連、配当＋流動性、権利日接近、上昇トレンド、毎週上昇、押し目、高値圏、出来高急増、低ボラティリティです。
候補を絞る出発点であり、効果を実証した売買戦略や将来収益の保証ではありません。

## チャートと銘柄分析

行をタップすると銘柄詳細とチャートを表示します。コードのタップでコピーできます。
チャートにタッチするか横に指を動かすと、最も近い日足終値に十字線を合わせます。
日付・価格・前の取引日の終値に対する騰落率・表示期間開始日に対する騰落率を表示します。
キーボードの左右矢印、Home、End でも操作できます。最初のデータで前日終値がない場合は前日比を表示しません。

選択中の API プロバイダーのキーを保存すると、銘柄詳細の「分析」が有効になります。
取得済みの価格・配当・指標とその基準日を API に送り、分析結果を表示します。
その下の質問欄から、同じ銘柄について続けて質問できます。
会話は銘柄とプロバイダーごとにこのページ内だけで保持し、再読み込みで消えます。
ウィンドウを閉じるか銘柄を切り替えると進行中のリクエストを中断します。
API が返した文字列は HTML として解釈せず、そのまま表示します。
分析は取得済み資料を根拠とし、最新ニュースや企業開示を追加取得する機能はありません。

## API キー

設定から OpenAI または Anthropic を選択してキーを保存します。
OpenAI は Responses API (gpt-4.1-mini)、Anthropic は Messages API (claude-haiku-4-5) を使用します。
キーは端末の localStorage に保存し、選択した API に直接送信します。
GitHub、データ生成処理、共有サーバーにキーや会話を保存しません。
キーがなくても式の編集・プリセット・スクリーニング・チャートは利用できます。

## 配当・権利日データ

Yahoo Finance の年間配当額と同時点の通常株価から配当利回りを計算します。
予想額がなければ過去実績を使い、予想/実績と取得日を表示します。
権利付き最終日は、取得した権利落ち日の直前の市場取引日です。
日本の祝日と米国市場の休場日を考慮します。配当の権利日であり、株主優待は含みません。
未取得の日付は推測せず、取得済みでも過去のままの場合があります。
情報は通常１日キャッシュし、通信失敗時には７日以内の保存値を使います。取得率は画面に表示します。

## 運用

Settings → Pages の Source を GitHub Actions に設定し、github-pages 環境から main のデプロイを許可します。
main 更新時、平日17:00 JST、および米国時間外取引終了後にデータ生成・公開します。
Actions → 定期スクリーニング → Run workflow でも手動実行できます。

```bash
pip install -r requirements.txt
python build_dataset.py
python -m http.server -d docs 8000
```

生成した docs/data/ は Git 管理せず、Pages の成果物として配信します。

## 検証

```bash
python -m unittest discover -s tests -p 'test_*.py'
python tests/gen_fixtures.py
node tests/parity.mjs
node tests/scripts.mjs
node tests/nl_responses.mjs
node tests/chart.mjs
node tests/analysis.mjs
node tests/stock_ai.mjs
```

画面テストでは API 応答を模擬し、式の生成・表示・実行、分析と会話の継続、キー設定、銘柄切替時の中断を確認します。
チャートのタッチ位置・座標倍率・十字線・騰落率も確認します。
旧条件評価の参照実装と parity テストはリポジトリに残していますが、現在の画面は式評価エンジンだけを使用します。

## 構成

- build_dataset.py / app/: 銘柄一覧、価格、配当データの取得と特徴量生成
- docs/index.html: 条件式入力、結果、銘柄詳細、分析・会話の画面
- docs/screen-script.js: 条件式パーサーと指標計算
- docs/chart-interaction.js: チャートのタッチ・キー操作
- docs/stock-ai.js: OpenAI Responses / Anthropic の共通クライアント
- .github/workflows/screening.yml: 検証、定期データ生成、Pages 公開

## セクター・業種と半導体関連

セクターと業種を選択して、現在の条件式に分類の条件を追加できます。自然言語も同じ式を生成します。

```
semiconductor == 1 && r3 >= 10
sector == "Technology" && dividend_yield >= 2
industry == "Semiconductor Equipment & Materials"
jpx_industry == "電気機器"
```

sector / industry は Yahoo Finance の分類です。東証の業種が未取得の場合は JPX の33業種を industry に補います。jpx_industry は JPX の業種です。半導体関連は、業種・企業名・事業説明に semiconductor / 半導体 の記載がある銘柄を対象とし、装置や材料も含みます。専業や完全な網羅性を保証する分類ではありません。判断元を銘柄詳細に表示し、分類情報がない銘柄は該当条件から除外します。分類更新時には古いキャッシュを再取得します。

自然言語の入力欄は選択中の API プロバイダーのキーが保存されているときだけ表示し、折り畳みません。

チャートは上下に余白を取り、曲線と十字線が同じスケールを使います。価格の最大値とマーカーが上端で切れないようにしています。「縦軸を0から表示」の切り替えで、自動範囲とゼロ起点を選べます。タッチ位置の値は日付、大きな価格、前日比と表示開始日比の２列カードで確認できます。
