セクター・業種から条件式を作る

半導体関連は、業種・企業名・事業説明に半導体の記載がある銘柄を対象とします。製造装置や材料も含み、専業・網羅性を保証する分類ではありません。

配当は年間配当額÷取得時株価。予想値を優先し、なければ過去実績を使います。権利付き最終日は取得した権利落ち日の直前の取引日です。配当の権利日を対象とし、株主優待は含みません。日付が過去のままの場合や未取得の場合があります。
