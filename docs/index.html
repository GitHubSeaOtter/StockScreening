対象

東証の内訳

条件の候補

目的に合わせて選ぶ出発点です。将来の収益を保証するものではありません。選択すると現在の条件を置き換えて実行します。

配当・権利日の範囲を指定
配当利回り 〜 %
権利付き最終日 〜

配当は年間配当額÷取得時株価。予想値を優先し、なければ過去実績を使います。権利付き最終日は取得した権利落ち日の直前の取引日です。配当の権利日を対象とし、株主優待は含みません。日付が過去のままの場合や未取得の場合があります。

条件(すべて AND)

当日の時間外価格がない銘柄は終値で判定します。騰落率の表示も選択した価格に合わせます。価格条件の単位は東証が円、米国が米ドルです。
🤖 自然言語で条件を指定(要 API キー)

例: 配当利回り3%以上で権利付き最終日まで30日以内、または20日移動平均より上でRSIが50未満
