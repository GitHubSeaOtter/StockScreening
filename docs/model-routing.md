# 実行時のモデル利用

スクリーニングの数値評価と指標計算はブラウザ内の条件式エンジンで行います。
自然言語からの条件指定では OpenAI Responses または Anthropic Messages を使い、単一の expression と市場・価格モード・未対応部分を構造化出力します。旧条件タイプのリストは生成しません。

銘柄詳細の分析・追加質問も同じ API クライアントを使います。
選択銘柄の取得済みデータと基準日を資料として渡し、銘柄ごとの会話を引き継ぎます。
OpenAI は gpt-4.1-mini、Anthropic は claude-haiku-4-5 です。

キーは端末の localStorage に保持し、ブラウザから選択 API に直接送信します。
API の応答は文字列として表示し、HTML やスクリプトとして実行しません。
